01 / GEOMETRY

动态星座覆盖图

旋转三维地球、播放轨道、查看地面站与伦敦—东京航线采样点。支持 Walker Delta / Star、多个轨道层和本机保存的新方案。

  • 输入高度、倾角、面数、面内星数和相位
  • 按 WGS84 椭球法向判断仰角接入
  • 下载配置 JSON 与 CZML
打开覆盖工具 →仅几何；未计入机械与光学误差。 02 / NETWORK

网络时延模拟

使用同一份星座配置构建快照图，计算传播、处理开销、路径与中断。网页提供几何估算；Python 提供现有工程约束模型。

  • 四邻居网格或无限终端的几何选边
  • 平均 RTT、在线 P99、P99−P1 与可用率
  • 下载 CSV、结果与配置
打开时延工具 →冻结时刻的对称 RTT；不是包级或运营商 SLA。

使用边界

绿色足印表示当前有仰角满足条件的卫星，不表示激光网络已连通。几何覆盖 100% 的有限采样结果也不证明永久连续服务。东京使用城市代理坐标；地面 RTT 对标数值是情景输入。

网页新配置只保存在你的浏览器或下载文件中，不会写入公共方案库。既有研究结果保留作示例，本项目停止扩大星座扫描。
